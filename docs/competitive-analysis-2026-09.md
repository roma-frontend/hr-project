# Конкурентный и продуктовый разбор Strata (HR-платформа)

> **Дата:** 2026-09-17 · **Метод:** инвентаризация кода + документации репозитория, сверка заявленных фич с фактической реализацией, сопоставление с открытыми данными вендоров.
> **Ограничение:** на момент разбора веб-поиск был недоступен, поэтому данные по армянскому рынку и свежие цены глобальных вендоров взяты из знаний модели и требуют **проверки на дату сделки**. Всё, что касается нашего продукта, проверено по репозиторию.
> **Связанные файлы:** `docs/gtm-playbook.md`, `docs/battlecards.md`, `src/lib/competitors.ts`, `ROADMAP.md`.

## 1. Что это за продукт (факты из кода)

**Strata** — многотенантная SaaS HR-платформа (HRIS + учёт времени + финансы + коммуникации) на Next.js 16 / React 19 / Convex, с армянской спецификой (SRC-отчётность, imID, Idram/ArCa, 4 языка, включая армянский).

### 1.1. Реальный масштаб (сверено с диском)

| Параметр          | Значение                                           | Комментарий                                         |
| ----------------- | -------------------------------------------------- | --------------------------------------------------- |
| Страницы дашборда | ~50 папок роутов под `(dashboard)`                 | 46+ модулей                                         |
| Backend Convex    | ~110 модулей + отдельные `schema/`                 | зрелая доменная модель                              |
| Биллинг-каталог   | **69 модулей** в `convex/billing/modules.ts`       | единый реестр, редактор тарифов управляется из него |
| Компоненты        | 500+                                               |                                                     |
| Языки             | EN / RU / HY / DE, 20+ namespace                   | HY покрыт лучше, чем писала старая дорожная карта   |
| Роли              | 5: superadmin, admin, supervisor, employee, driver |                                                     |
| Тесты             | 650+ файлов, порог покрытия ~68%                   |                                                     |

### 1.2. Модули, которые **реально есть** (и часть отсутствует в старой дорожной карте)

**Кадры:** сотрудники, департаменты, должности, орг. структура (React Flow), профили, испытательный срок, директория, команды.
**Время:** посещаемость (распознавание лиц), учёт времени, отпуска/отгулы, календарь, переработки, графики смен (+обмен сменами), переговорные, видеоконференции (LiveKit).
**Талант:** подбор (ATS + публичный careers), онбординг, оффбординг, обучение (LMS), найм-пакеты, **succession planning (9-box)**, **career paths (skill matrix, треки, gap-анализ, менторство)**.
**Эффективность:** performance/360, OKR/цели, strategy maps, признание (kudos + баллы + бейджи), rewards, опросы/eNPS.
**Финансы:** зарплата (армянские налоги), компенсации (грейды, бонусы), расходы (политики/лимиты), бенефиты (кошельки/клеймы), активы, отчёты, аналитика.
**Коммуникации:** чат, новости, approvals, рассылки, тикеты поддержки.
**Документы:** библиотека, версии, e-подписи (canvas + аудит + PDF), конструктор документов.
**Платформа:** multi-tenant биллинг (Stripe + локальные PSP), публичный API v1 + вебхуки, SSO (SAML/OIDC), SCIM, TOTP, passkeys, аудит, GDPR, бэкапы, автоматизация (визуальный конструктор — пока только у оператора), Telegram.
**AI:** AI-ассистент, AI-оценщик, AI-рекрутинг, AI-редактор сайта, прогноз оттока (`attritionRisk.ts`).

> **Вывод:** это не MVP. По широте модулей продукт сопоставим с mid-market HRIS-наборами (Personio/BambooHR/HiBob), а по отдельным направлениям (локальный комплаенс, видео, чат, e-sign, водители, shifts) — шире.

### 1.3. Плюсы архитектуры

- Мультитенантность с серверным enforcement прав (тарифы блокируются на сервере, не только в UI) — редко и правильно.
- Реальный RBAC + аудит + SSO/SCIM — enterprise-ready каркас.
- 4 языка с автопроверкой паритета ключей в CI — сильный сигнал для армянского рынка.
- i18n, SEO-страницы `/compare`, тесты производительности (k6), Sentry/OTel, границы бандла.

### 1.4. Минусы и риски (технические)

| Риск                                                                                                                        | Почему важно                                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Нет нативных приложений** — только PWA, и SW, похоже, не регистрируется глобально (в `src` нет `navigator.serviceWorker`) | У всех конкурентов есть iOS/Android. Для сменного/линейного персонала это блокер.                                                                                                                                                       |
| **Биометрия (распознавание лиц) в браузере**                                                                                | Чувствительные данные; нужна явная правовая база (Закон РА о персональных данных / GDPR), согласие, хранение шаблонов. Регуляторный риск выше, чем продуктовая ценность.                                                                |
| **SharePoint как источник истины**                                                                                          | Наследие корпоративного сценария; для современного SaaS это ограничение, а не фича.                                                                                                                                                     |
| **Armsoft-«интеграция» — это generic endpoint + cron**, а не сертифицированный коннектор                                    | В таблице сравнения строка выглядит как `yes`, фактически — настраиваемый скелет. Риск завышенного ожидания у главбуха.                                                                                                                 |
| **Bleeding edge** (Next 16, React 19, Turbopack, Convex)                                                                    | Быстро, но выше риск нестабильности и зависимости от одного вендора БД.                                                                                                                                                                 |
| **Широта без глубины**                                                                                                      | 69 модулей при ~68% покрытии и малой команде → долг сопровождения; «хорошо во всём, лучший ни в чём».                                                                                                                                   |
| **Pricing-модель противоречит GTM**                                                                                         | Прайс — **плоский**: Starter $29/мес, Pro $79/мес (калькулятор считает $1.58/место при 50 местах). GTM-док при этом утверждает «цена за сотрудника». Это либо осознанный land-grab, либо ошибка, которая убьёт юнит-экономику на росте. |

## 3. Конкурируем ли мы?

| Сегмент                                         | Вердикт                    | Почему                                                                      |
| ----------------------------------------------- | -------------------------- | --------------------------------------------------------------------------- |
| Армянское юрлицо, 20–300 чел., сменный персонал | **Да, уверенно**           | Локализация + время + графики + язык + цена + один вендор                   |
| Армянский офис МНК                              | **Да, как локальный слой** | Глобальные процессы остаются у головного офиса, локальный комплаенс — у нас |
| Диаспора / русскоязычный CIS                    | **Частично**               | Выигрываем языком и ценой, но здесь есть PeopleForce/1C и слабее бренд      |
| Mid-enterprise Армении (банки, телеком)         | **Пока нет**               | Нет SOC 2, нет enterprise-репутации, часто нужен SAP/Oracle                 |
| Global head-to-head (США/ЕС)                    | **Нет и не нужно**         | Проигрываем бренд, мобильные, payroll/EOR, экосистему                       |

**Итог:** продукт реально конкурентоспособен в узкой, но защищённой нише (Армения + диаспора + CIS SMB) и как «локальный слой» для МНК. Лобовая глобальная конкуренция — стратегическая ошибка.

## 4. Где мы сильны (moat)

1. **Локальный армянский комплаенс** — SRC-экспорт, налоги (20% НДФЛ, накопительная пенсия, военный сбор, медстрахование), ՀՎՀՀ, Idram/ArCa, imID. Этого нет ни у одного западного вендора и это то, что спрашивает главбух первым.
2. **Консолидация** — HRIS + время + деньги + чат + видео + e-sign + задачи + проекты в одной подписке.
3. **Язык** — армянский UI и поддержка, проверка паритета ключей в CI.
4. **Серверный enforcement тарифов** — редкая зрелость для стартапа.
5. **API с Pro** (а не с Enterprise) — правильное решение, совпадает с рынком.
6. **Уникальные модули** — drivers, shifts+swaps, strategy maps, face-kiosk, succession, career-paths, imID e-sign.
7. **Открытая честная таблица сравнения** с проигрышными строками — доверие как оружие.

## 5. Где проигрываем (gaps)

**Продуктовые:**

1. Нет нативных мобильных приложений (PWA слабый, SW не глобально).
2. Зарплата: нет банковских платёжек, нет реальных коннекторов к Armsoft/1C (только скелет), нет мультистран.
3. Нет устройства-интеграций биометрии (ZKTeco/Suprema) — только браузерная камера.
4. Нет единого конструктора отчётов + scheduled exports.
5. Workflow builder не продан тенантам (только оператор).
6. Нет marketplace интеграций (Slack/Teams/Jira/бухгалтерия/джоб-борды).
7. Аналитика без бенчмаркинга зарплат и headcount-планирования.
8. Succession/career — есть, но неглубоко (нет калибровочных сессий, привязки к компенсации).
9. Нет SOC 2 (и, вероятно, ISO 27001) — блокер enterprise-закупок.

**Коммерческие:**

1. Прайс плоский и противоречит GTM; риск юнит-экономики.
2. Нет публичного прайс-листа с точными цифрами / нет «from» для Enterprise.
3. Нет кейсов, партнёрской программы (бухгалтеры/интеграторы), контент-плана.
4. TAM Армении мал → нужен выход в регион (Грузия, Казахстан, ОАЭ/диаспора).
5. Люди копируют дизайн PeopleForce — риск узнаваемости/вторичности бренда.
6. Данные: Vercel EU + Convex — вопрос data residency для консервативных клиентов.

## 6. Рекомендации (приоритизированы)

### P0 — закрыть то, что блокирует сделки (0–2 мес.)

1. **Мобильный клиент.** React Native/Expo (общая кодовая база) либо, как быстрый шаг, довести PWA: глобальная регистрация SW, offline-кэш дашборда, Web Push, quick actions «одобрить отпуск», «отметиться», «посмотреть смену». Для линейного персонала это конкурентное преимущество, а не галочка.
2. **Банковские платёжные поручения** (Армения) + **реальные коннекторы Armsoft/1C** (обмен проводками/начислениями). Это закрывает главбуха и превращает его из блокера в канал.
3. **Публичный прайс + выравнивание модели.** Определиться: per-seat с минимальным счётом ИЛИ per-seat за модуль. Плоские $29/$79 при 50 местах = $1.58/место — продавать нельзя, если горизонт >1 год. Ввести per-seat + volume-tiers, оставить бесплатный trial.
4. **Правовая база под биометрию** (согласие, хранение шаблонов, срок, DPA) + документ data residency. Без этого face-kiosk — юридический риск.
5. **Упаковка кейсов:** 3 публичных кейса «до/после» с цифрами (часы, ₽/$ экономия).

### P1 — усилить дифференциацию (2–5 мес.)

6. **Workflow builder тенантам** — визуальная автоматизация как продаваемая фича (сейчас спрятана у суперадмина). Конкуренты продают это отдельно.
7. **Marketplace интеграций:** Slack/Teams (уведомления), Google/Outlook (есть), Jira/Asana, бухгалтерия, джоб-борды (Staff.am, hh), ZKTeco/Suprema.
8. **Единый конструктор отчётов** + запланированные экспорты по email (cron + Resend).
9. **Глубина succession/career:** калибровочные сессии 9-box, привязка к компенсации и LMS-рекомендациям, «what-if» на уход.
10. **AI как дифференциатор:** авто-саммари откликов, AI-скоринг кандидатов, AI-ответы по политикам на армянском, прогноз attrition → рекомендации (уже есть `attritionRisk`, довести до actionable).

### P2 — масштаб и защита (5–12 мес.)

11. **Выход в регион:** локализация под Грузию (аналогичный локальный комплаенс) и/или Казахстан, ОАЭ/диаспору. UB — один рынок слишком мал.
12. **SOC 2 Type II + ISO 27001** — открывает enterprise и вузы/банки.
13. **Партнёрская программа** с бухгалтерами/аудиторами/интеграторами 1C/Armsoft — это главный канал в Армении.
14. **Бенчмаркинг зарплат** (армянский рынок) — уникальные данные, которых нет ни у кого.
15. **Бренд:** уйти от копирования PeopleForce, выработать свой визуальный язык.

### Что НЕ делать

- Не обещать глобальный payroll/EOR (это Deel) — продавать дополнение.
- Не идти в enterprise-закупки до SOC 2.
- Не демпинговать и не продавать «69 модулей».
- Не прятать проигрышные строки в сравнении — доверие и есть преимущество.

## 7. Одной строкой

Strata — зрелый, необычно широкий и технически грамотный HR-продукт с **настоящим армянским moat** и честным позиционированием. Он **выигрывает локально** (Армения/диаспора/CIS SMB и как локальный слой для МНК) и **не должен пытаться выиграть глобально**. Три вещи отделяют его от доминирования в нише: **нативное мобильное приложение, реальная платёжно-бухгалтерская интеграция и внятная per-seat цена**. Дальше — регион и сертификаты.
