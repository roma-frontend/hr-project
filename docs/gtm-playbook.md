> **Назначение:** документ для продаж и маркетинга, а не для инженеров. Отвечает на три вопроса: кому мы продаём, против кого выигрываем и по какой цене.

## 1. Позиционирование

**Категория:** HR-платформа (HRIS + учёт времени + коммуникации), а не «надстройка для перформанса» и не «global payroll».

**Формулировка (одна строка):**

> Единственная HR-платформа, которая говорит с налоговой Армении и с вашими сотрудниками на их языке — и закрывает кадры, время, деньги и внутренние коммуникации в одном месте.

**Позиционирование по формуле Дюна (для внутреннего использования):**
| Элемент | Значение |
| --- | --- |
| Для кого (competitive alternative) | Армянские и СНГ-компании, которые сейчас собирают HR из BambooHR/Personio + Excel + Telegram + локального бухгалтерского софта |
| Что не так (проблема) | Ни один мировой вендор не делает армянскую отчётность, локальные платёжные методы и армянский интерфейс. Компания платит за 4 подписки и всё равно доделывает отчёты руками |
| Наш подход (как) | Одна платформа, в которой эти фичи не «интеграции», а нативные модули |
| В чём ценность | Меньше ручной работы, один счёт, никакого двойного ввода данных, отчётность уходит в срок |
| Доказательство | `/compare` — 29 возможностей против 6 вендоров, включая строки, где мы проигрываем |

**Почему не «мы лучше Personio вообще»:** такую заявку легко опровергнуть одним вебинар-экраном Personio. Мы выигрываем на конкретном наборе требований, и публичная таблица показывает на каком.

## 3. Четыре опоры сообщения

1. **Локальный комплаенс — не фича, а входной билет.** Готовый экспорт для налоговой Армении (SRC), синхронизация с Armsoft, вход через imID, платежи Idram/ArCa. Это то, чего нет ни у одного конкурента из таблицы, и то, о чём спрашивает главбух на первом звонке.
2. **Один продукт вместо пяти.** Посещаемость с распознаванием лиц, графики смен, отпуска, задачи, проекты, чат, видеовстречи, документы и подписи — в одной системе. Считайте это в деньгах на демо: сравните со суммой Slack + Zoom + таск-трекер + e-sign + транспортом данных между ними.
3. **Язык как уважение.** Интерфейс и поддержка на армянском (плюс русский) — не «мы обещаем перевести», а есть сегодня.
4. **API с Pro.** Интеграции не для избранных: публичный API и вебхуки доступны на среднем тарифе, а не только на Enterprise.

**Чего в сообщении быть не должно:** «50 модулей», «лучше всех», «дешевле всех». Модули никого не продают; продаёт снятая боль на конкретном процессе.

## 4. Тарифы и упаковка

### 4.0. Модель: per-seat + volume-тиры (с 2026-09-17)

Раньше тариф был плоским ($29 / $79 за всю команду): 50 сотрудников на Pro = **$1.58/место** — на порядок ниже всех конкурентов и экономически нежизнеспособно. Теперь цена — **за сотрудника в месяц**, с объёмными тирами: при росте команды вся команда переходит на ставку более низкого тира (volume pricing).

| План       | Места         | Ставка/место/мес (мес.) | Объёмные тиры                                |
| ---------- | ------------- | ----------------------- | -------------------------------------------- |
| Starter    | 5–25          | $4                      | 5+ → $4; 15+ → $3.5                          |
| Pro        | 10–300        | $8                      | 10+ → $8; 50+ → $7; 100+ → $5.5; 250+ → $4.5 |
| Enterprise | 100+ (custom) | «от $12»                | индивидуально (годовая −25%)                 |

Годовая оплата: **−20%** (Enterprise −25%). Входные суммы: Starter от $20/мес (5 мест), Pro от $80/мес (10 мест). Ставки за место в годовом эквиваленте: Starter $3.2, Pro $6.4.

**Почему именно эти цифры (решение от 2026-09-17: «по средней рынка»).** Первая per-seat версия ($3/$6) оказалась ниже рынка почти по всем тирам, что оставляло деньги на столе и мешало продавать против BambooHR «сверху», а не «снизу». Ориентир — медиана SMB-HRIS за место в месяц: PeopleForce ≈ $3–5, Factorial ≈ €4–6, Personio ≈ €4.5–9, BambooHR ≈ $6.5–9.5, Rippling ≈ $8–10, HiBob ≈ $10–14 → **медиана ≈ $7**. Итог: вход $8/место у Pro чуть выше медианы (мы даём больше модулей в одной подписке), Starter $4 — входной сегмент, Enterprise «от $12» — премиум-полоса. Локальные 1C/Armsoft/Odoo (~$1–4 + внедрение) мы по-прежнему дороже — против них играем не ценой, а готовностью из коробки и отсутствием доработок.

⚠️ Цены глобальных вендоров — из знаний модели, публичные прайсы меняются и часто не опубликованы; **проверять перед каждой крупной сделкой**. Наша модель — `src/lib/pricing.ts`.

**Плоский тариф мы больше не продаём.**

Канонический источник модели — `src/lib/pricing.ts`; базовые per-seat цены и тиры — в `convex/billing/defaults.ts`; совпадение проверяет тест `src/__tests__/pricing.test.ts`. Checkout в Stripe передаёт `quantity = число мест`.

### 4.1. Что изменилось 2026-09-16

| Было                               | Стало                                                     | Зачем                                                                                                                                          |
| ---------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Публичный API только на Enterprise | **API на Pro** (25 000 вызовов/мес), Enterprise — 100 000 | Все шесть конкурентов дают API на среднем тарифе. Мы выглядели единственным, кто прячет API за Enterprise, — это билось на первом же сравнении |
| Локальные платежи не готовы        | Idram / ArCa доступны как способ оплаты                   | Малый бизнес в Армении платит картой местного банка, а не международной                                                                        |
| Каталог модулей включал `coming`   | API переведён в активные                                  | Тариф должен быть исполнимым, а не декларативным                                                                                               |

Технически это в `convex/billing/defaults.ts` (`DEFAULT_ENTITLEMENTS.pro.apiAccess`) и в каталоге модулей `convex/billing/modules.ts`; версии планов фиксируются при публикации, так что у действующих клиентов права не отбираются.

### 4.2. Логика упаковки

- **Starter** (5–25 мест) — входной продукт: кадры, отпуска, посещаемость, задачи, документы. API нет намеренно: команда из 5–25 человек интеграции не строит, а лимит создаёт честный повод апгрейда.
- **Pro** (10–300) — всё, что делает HR-отдел: подбор, онбординг, оценка, OKR, зарплата, отчётность, аналитика, AI-ассистент, **API**.
- **Enterprise** (100+, custom) — вебинары в видеоконференциях, приоритетная поддержка, кастомные лимиты, SSO/SCIM, аудит.

> Лимиты мест в тарифах (25 / 300 / без лимита) — это **потолок плана** и повод апгрейда, а не фиксированный счёт: платите за фактическое число мест по объёмной ставке.

### 4.3. Прайсинг: принципы

1. **Цена за сотрудника, а не за модуль.** Конкуренты продают модули; мы продаём снятую сложность. Модульная нарезка возвращает клиента в мир пяти подписок.
2. **Объёмные тиры, а не «звоните, узнаете».** Starter/Pro считаются на сайте калькулятором; custom только Enterprise.
3. **Локальные платежи = снижение трения, а не скидка.** Оплата Idram/ArCa должна быть так же проста, как карта.
4. **Не демпинговать.** Наш аргумент — совокупная стоимость (заменяем 3–5 сервисов), а не «дешевле BambooHR».

## 8. Что НЕ делать

1. **Не обещать глобальный payroll/EOR.** Это другая индустрия с другой экономикой; попытка тягаться с Deel сожжёт ресурс.
2. **Не идти в enterprise-закупки до SOC 2.** Продажа в компанию, где безопасность проверяет внешний аудитор, без сертификата = потерянные кварталы.
3. **Не прятать слабые строки.** Мы публикуем таблицу с проигрышными строками именно для того, чтобы остальным верили. Как только начнём подчищать — потеряем единственное преимущество в доверии.
4. **Не строить сделку на цене.** Наш аргумент — локальный комплаенс и консолидация. Демпинг превращает продукт в commodity.
5. **Не продавать «46 модулей».** Продавать надо один процесс, который у клиента болит сильнее всего.
