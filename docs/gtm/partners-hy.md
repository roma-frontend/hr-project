# Strata — գործընկերների տեսլական

> **Հաշվապահների, աուդիտորների, ինտեգրատորների և ռեսելերների համար · 2026 թ. սեպտեմբեր։**
> Այս փաստաթուղթը բացատրում է, թե ինչ է Strata-ն, որ հաճախորդներին է համապատասխանում և ինչպես
> է աշխատում գործընկերությունը։ Հաճախորդների համար ուղղված համեմատության էջերը՝ `/compare`,
> ներքին վաճառքի խաղագիրքը՝ `docs/gtm-playbook.md`։

---

## 1. Ինչ է Strata-ն

HR հարթակ Հայաստանում և ԱՊՀ-ում գործող ընկերությունների համար՝ աշխատակիցների գրառումներ,
կենսաչափական և դեմքի ճանաչմամբ հաճախումներ, արձակուրդներ, հերթափոխերի պլանավորում,
աշխատավարձ ՀՀ ՊԵԿ-ի հաշվետվությամբ, տեղական վճարումներ (Idram/ArCa), հավաքագրում,
աշխատանքի ընդունում, կատարողական, ուսուցում, փաստաթղթեր էլեկտրոնային ստորագրություններով
և ներկառուցված չատ ու տեսահանդիպումներ՝ մեկ համակարգ, տեղայնացված հայերենով, ռուսերենով,
անգլերենով և գերմաներենով։

Ձեր հաճախորդների համար դա սովորաբար նշանակում է փոխարինել հետևյալ համադրությունը՝
աղյուսակներ, Telegram-ի հաճախումների խմբեր, առաջադրանքների մեսենջեր, առանձին
ստորագրության գործիք և ձեռքով աշխատավարձի նախապատրաստում։

## 2. Որ հաճախորդներն են համապատասխանում

**Լավ համապատասխանություն.**

- Հայկական ընկերություններ 20–300 մարդով՝ գրասենյակային կամ հերթափոխային/դաշտային
  անձնակազմով։
- Միջազգային խմբերի հայկական գրասենյակներ, որոնց պետք է տեղական հաշվետվողական շերտը։
- Սփյուռքի բիզնեսներ, որոնք ուզում են հայերեն կամ ռուսերեն ինտերֆեյս անձնակազմի համար։
- Ընկերություններ, որոնք աշխատավարձ են վճարում տեղական բանկերով և օգտվում են Armsoft-ից
  կամ 1C-ից։

**Համապատասխան չէ (ազնվորեն, դա ժամանակ է խնայում բոլորի համար).**

- Ընկերություններ, որոնց պետք է աշխատավարձ 10+ երկրում՝ դա EOR ապրանք է։
- Ընկերություններ, որոնց գնումները պահանջում են SOC 2 Type II հավաստագիր այսօր։
- ԱՄՆ-ում գրանցված ընկերություններ, որոնց հիմնական կարիքը ամերիկյան աշխատավարձն է։

## 3. Ինչ են ստանում գործընկերները

| Գործընկեր                     | Դեր                                                                            | Ինչ եք ստանում                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| Հաշվապահներ և աուդիտորներ     | Խորհուրդ են տալիս Strata-ն հաճախորդներին, ըստ ցանկության՝ վարում են նրանց HR-ը | Կրկնվող գործակալական վարձատրություն, ձեր ֆիրմայի համար անվճար ներքին աշխատանքային տարածք           |
| Armsoft / 1C ինտեգրատորներ    | Ներդնում են Strata-ն ձեր հաշվապահական նախագծերի կողքին                         | Ներդրման վարձատրություն, Armsoft-ի համաժամեցման մոդուլը հանում է տվյալների կրկնօրինակման աշխատանքը |
| Ռեսելերներ / HR խորհրդատուներ | Վաճառում և ներդնում են                                                         | Մարժա բաժանորդագրության վրա առաջին տարվա ընթացքում, համատեղ ներդրման նյութեր                       |

Բոլորի համար ընդհանուր է՝ **ուսուցում, դեմո տարածք, չորս լեզվով մարքեթինգային նյութեր
և ուղիղ կապ ապրանքային թիմի հետ։** Գործընկերների ֆունկցիոնալ պահանջները առաջնահերթ
են հաճախորդի պահանջների նման, որովհետև գործընկերներն ավելի շատ հաճախորդ են տեսնում, քան մենք։

## 4. Հինգ րոպեանոց ներկայացում հաճախորդին

1. **«Ձեր հաճախումները Telegram-ի խմբում են, իսկ արձակուրդները՝ աղյուսակում»։**
   Strata-ն փոխարինում է երկուսին՝ անհրաժեշտության դեպքում դեմքի ճանաչմամբ տերմինալներով։
2. **«Ձեր աշխատավարձի պատասխանատուն ՊԵԿ-ի հաշվետվությունը պատրաստում է ձեռքով»։**
   Strata-ն ստեղծում է ՊԵԿ-ի համար պատրաստ արտահանում (եկամտահարկ, կուտակային
   կենսաթոշիկ, զինծառայության դրոշմանիշ, առողջապահության ապահովագրություն, ՀՎՀՀ)
   ստուգված, ձևավորված թերթիկով։
3. **«Ձեր անձնակազմը կարդում է հայերեն կամ ռուսերեն»։** Ինտերֆեյսն ու աջակցությունը
   բնիկ են, ոչ թե մեքենայական թարգմանությամբ, չորս լեզուների բանալիների պարիտետը
   ավտոմատ ստուգվում է ամեն թողարկման ժամանակ։
4. **«Դուք վճարում եք չորս գործիքի համար և տվյալներ եք տեղափոխում դրանց միջև»։**
   Մեկ ապրանք, մեկ հաշիվ, առանց կրկնակի ներածման՝ ներառյալ ստորագրություններն ու
   փաստաթղթերի ձևանմուշները։
5. **«Կարող եք փորձել նախքան որոշելը»։** Անվճար մեկնարկ, աշխատակիցների ներբեռնում,
   գնահատում ձեր տվյալներով։ 20–100 մարդու ընկերության համար ներդրման նախագիծ պետք չէ։

## 5. Այն դիմադրությունները, որ կլսեք, և պատասխանները

- **«Արդեն օգտվում ենք BambooHR / Personio / HiBob-ից»։** Հիանալի՝ պահեք
  գլոբալ գործընթացների համար։ Ոչ մեկը չի ստեղծում հայկական ՊԵԿ հաշվետվություն, չի
  համաժամեցնում Armsoft-ի հետ և չունի հայերեն ինտերֆեյս։ Strata-ն ծածկում է տեղական
  շերտը (և սովորաբար փոխարինում է դրա շուրջ աղյուսակային աշխատանքը)։
- **«Անվտանգ է»։** Դերային մուտք, աուդիտի գրառումներ, SSO (SAML/OIDC), SCIM
  պրովիժինինգ, անվտանգության կենտրոն և SOC 2 ապացույցների ավտոմատ հավաքում, աուդիտն
  ընթացքի մեջ է։ Տվյալների արտահանում և հրապարակային API կան յուրաքանչյուր սակագնում՝
  հաճախորդը երբեք փակված չէ։
- **«Ի՞նչ եթե դուք անհետանաք»։** Նույն պատասխանը՝ ամբողջական տվյալների արտահանում,
  API մուտք, հայկական իրավաբանական անձ։ Գումարած՝ մեր գինը աշխատակցի համար է,
  հրապարակված է և էժան է այն գործիքների գումարից, որ փոխարինում ենք։
- **«Մեզ միայն հաճախումներ են պետք»։** Սկսեք ժամանակի մոդուլից։ Շատ հաճախորդներ
  եռամսյակի ընթացքում ավելացնում են արձակուրդներն ու փաստաթղթերը, որովհետև տվյալներն
  արդեն համակարգում են։

## 6. Ինչպես է աշխատում առևտրային հարաբերությունը

1. **Ծանոթացման զանգ** — համաձայնեցնում ենք ձեր հաճախորդների բազան և գործընկերության տեսակը։
2. **Դեմո տարածք + ուսուցում** — ձեր թիմը ստանում է աշխատանքային տարածք և ներկայացում։
3. **Դուք ներկայացնում եք, մենք ավարտում ենք** — կամ ամբողջ ցիկլը վարում եք ինքներդ, երկուսն էլ եղած տարբերակներ են։
4. **Գործակալական** — կրկնվող բաժին ուղղորդված բաժանորդագրություններից, վճարվում է ամսական, ամրագրված է գործընկերային պայմանագրում։
5. **Աջակցության բաժանում** — առաջին գծի աջակցությունը մնում է հաճախորդի մոտ, դուք երբեք
   մեր helpdesk-ը չեք դառնում։

## 7. Առկա նյութեր

- Հրապարակային համեմատության էջեր՝ `/compare` (նաև հայերեն, ռուսերեն, գերմաներեն)։
- Չորս լեզվով ապրանքային ինտերֆեյս՝ ցուցադրեք հաճախորդներին իրենց լեզվով։
- Ինտեգրացիաների ուղեցույց (`.docx` գեներատոր՝ `npm run docs:user-guide`)՝ SSO, SCIM,
  վեբհուքեր, հրապարակային API և տեղական վճարումներ։
- ՊԵԿ արտահանման նմուշ և Armsoft-ի համաժամեցման սպեցիֆիկացիա՝ հարցմամբ։

## 8. Կապ

Գործընկերություններ՝ **office@** (հասցեն լենդինգում) — «partner» նշումով վերնագրում և
գործընկերության երեք տեսակներից որն է վերաբերում. պայմանագրի նախագիծը և դեմո տարածքը
կստանաք նույն շաբաթում։
